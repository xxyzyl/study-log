# 每日学习记录

每天把学习内容发到当前聊天，由助手整理为 Markdown 日志，提交并同步到 GitHub。

## 记录方式

- 无须固定格式，可以直接发送学习内容、笔记、做题情况和疑问。
- 按北京时间归档；明确指定日期时使用指定日期。
- 日志路径：`daily/YYYY/MM/YYYY-MM-DD.md`，同一天的补充合并进同一份文件。
- 保留原始学习内容，区分实际完成、待解决问题和后续计划。
- 未提供的学习时长、题量、正确率和掌握程度不推测。
- 每次更新后提交、同步，并返回对应日志链接；同步失败则明确说明。
